# Project instructions

## Review subagents

The project owner gives standing permission to launch read-only review subagents for changes in this repository without asking for confirmation. This includes independent PR reviews and fresh review rounds after findings are addressed.

Keep each review scoped to the requested work. Reviewers may inspect code and run relevant checks, but must not edit files, post external messages, merge PRs, or deploy. The parent agent handles findings and records an independent review only for the exact commit reviewed.

This permission covers review delegation. Follow the repository's existing CI, independent review, merge, and deployment requirements.
